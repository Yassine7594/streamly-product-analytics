# Données Streamly

Ce projet utilise un jeu de données synthétique composé de quatre tables :

- `users` : informations relatives aux utilisateurs.
- `contents` : catalogue des contenus.
- `watch_events` : historique des visionnages.
- `subscriptions` : historique des abonnements.

Les données sont fictives et utilisées exclusivement à des fins pédagogiques et de démonstration.

Les fichiers sources ne sont pas publiés dans ce dépôt pour le moment.
